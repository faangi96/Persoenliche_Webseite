# Hinweis zu den SQL-Dateien

Dieses Repository enthält SQL-Dateien, die Bestandteil einiger Funktionen der Webseite sind oder sich in der Entwicklung neuer Funktionen befinden.

**Wichtig:** GitHub Pages unterstützt keine serverseitigen Datenbanken und führt keine SQL-Abfragen aus. Daher werden die SQL-Dateien zwar im Repository gespeichert, können über GitHub Pages jedoch nicht ausgeführt werden und haben dort keine Funktion.

Die Dateien dienen der Dokumentation, Aufbewahrung und Weiterentwicklung des Projektcodes. Um die SQL-Abfragen auszuführen und die Datenbankfunktionen zu nutzen, ist ein entsprechendes Datenbanksystem wie beispielsweise MySQL erforderlich.
