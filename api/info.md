 Hinweis zu den PHP-Dateien

Dieses Repository enthält PHP-Dateien, die Bestandteil einiger Funktionen der Webseite bzw. Teil in der Entwicklung neuer Funktionen sind.

**Wichtig:** GitHub Pages unterstützt keine serverseitige Ausführung von PHP. Daher werden die PHP-Dateien zwar im Repository gespeichert, können über GitHub Pages jedoch nicht ausgeführt werden und haben dort keine Funktion.

Die Dateien dienen lediglich der Dokumentation und Aufbewahrung des Projektcodes. Eine Ausführung der PHP-Skripte ist erst auf einem Webserver mit entsprechender PHP-Unterstützung möglich.
